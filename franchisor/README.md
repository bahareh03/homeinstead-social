# Franchisor monthly content

Each month, make a folder named after the month and upload the content you want to use:

```
franchisor/2026-11/winter-wellbeing.jpg
franchisor/2026-11/winter-wellbeing.txt   <- caption from Home Instead UK (optional)
```

The workflow uses **3 a month**, on Tuesdays (catching up later in the month if any are missed), in file-name order. Put more than 3 in if you like; the extras are ignored. To upload on GitHub: open this folder → **Add file → Upload files**.
